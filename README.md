# KSC 썬릿밸리 패치 배포

친구들에게는 **[최신 KSC-Patcher.exe 다운로드](https://github.com/friedSaewoo/ksc-patcher-distribution/releases/latest)** 링크만 전달하면 됩니다. GitHub 로그인·토큰·JSON 주소 입력은 필요 없습니다.

## 사용 순서
1. Minecraft Java와 CurseForge를 설치합니다.
2. KSC-Patcher.exe 실행. 기본팩이 없으면 **기본팩 설치** 버튼으로 Society: Sunlit Valley **4.1.5A**를 CurseForge에 설치합니다. 설치 확인은 CurseForge 화면에서 진행합니다.
3. 설치 완료 후 **프로필 다시 검색**. 프로필이 하나면 자동 선택됩니다. 사용자 지정 경로라 검색되지 않으면 **직접 찾기**로 한 번 선택합니다.
4. Minecraft를 종료한 상태에서 **패치 검사 → 패치 적용**.
5. 완료 후 CurseForge에서 해당 프로필의 **플레이**를 누릅니다.

기본팩이 이미 있으면 2번의 기본팩 설치는 생략합니다. 게임 계정 로그인은 Minecraft/CurseForge 런처에서 본인이 직접 합니다.

## 배포 내용
- 공식 Society: Sunlit Valley 4.1.5A 클라이언트의 모드 351개·리소스팩 15개·셰이더 1개를 정확한 버전으로 관리합니다.
- 추가: Emotecraft 2.2.7-b.build.50 + Simple Voice Chat 2.6.22. 총 모드353개/관리파일369개.
- 공개된 원본 배포 URL에서 파일을 직접 받으며, 이 저장소는 타 제작자의 모드 JAR나 기본팩 ZIP을 재호스팅하지 않습니다.
- 개인 키·음량·그래픽 설정, 마이크 장치·음성 설정, 월드·스크린샷은 덮어쓰지 않습니다. 셰이더 파일을 검증할 뿐 사용 설정을 강제로 켜지 않습니다.
- 패치 주소가 EXE에 내장되어 있어 모드/파일 업데이트 때마다 EXE를 새로 받을 필요는 없습니다. 패치기 자체 기능 업데이트는 별도입니다.
- 서명되지 않은 EXE는 Windows SmartScreen 경고가 날 수 있습니다. 백신을 끄지 말고 출처와 SHA256SUMS.txt를 확인하세요.

## 운영 정보
소스 코드는 별도 비공개 저장소에서 관리됩니다. 이 저장소에는 공개 매니페스트와 우리 패치기 실행 파일만 배포합니다. 계정·비밀번호·인증키를 포함하지 않습니다.

프로그램 설치/검증 테스트와 실제 Minecraft 접속·음성 통화 테스트는 별개입니다. 게임 서버가 꺼져 있거나 음성 모드가 서버에 반영되기 전에는 접속/음성을 확인할 수 없습니다.
